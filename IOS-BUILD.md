# Vault — iOS Build & Run Guide (Mac + Xcode)

Everything you need to run Vault on the iOS Simulator or a real iPhone, and to
ship it via TestFlight. All commands run on your Mac in Terminal.

## 1. Prerequisites

- macOS with **Xcode** installed (from the Mac App Store)
- Open Xcode once after installing so it finishes its first-launch setup
  (accept the license, let it install components)
- **Node.js 20 LTS** — install from https://nodejs.org or via Homebrew:
  `brew install node@20`
- **CocoaPods**: `sudo gem install cocoapods`
- An **Apple Developer account** (only needed for real-device / TestFlight
  builds — free Apple ID works for the Simulator)

## 2. Get the code

```bash
git clone https://github.com/muhammadtalhaishtiaq/vault.git
cd vault
npm install
```

## 3. Run on the iOS Simulator (fastest way to see the app)

```bash
npx expo run:ios
```

What this does:
1. `expo prebuild` generates the native `ios/` project from `app.json`
   (bundle id `ai.vault.private`, permissions, plugins)
2. Installs CocoaPods dependencies
3. Builds the app and launches it on the iOS Simulator

If the Simulator doesn't open automatically: open Xcode → **Xcode menu →
Open Developer Tool → Simulator**, then re-run the command.

To run on a **specific simulator** (e.g. iPhone 17 Pro):

```bash
npx expo run:ios --device "iPhone 17 Pro"
```

List available simulators with: `xcrun simctl list devices available`

## 4. Open the native project in Xcode directly

After the first `npx expo run:ios` (or `npx expo prebuild`), open:

```
ios/Vault.xcworkspace     ← open THIS, not the .xcodeproj
```

Then press **⌘R** to build & run on the selected simulator/device.

## 5. Run on a real iPhone (development)

1. Connect your iPhone via USB
2. In Xcode, select your iPhone as the run destination (top toolbar)
3. Xcode → **Settings → Accounts** — sign in with your Apple ID
4. Select the **Vault** target → **Signing & Capabilities** → pick your
   **Team**. Xcode will manage the provisioning profile automatically.
5. Trust the developer on the iPhone: **Settings → General → VPN & Device
   Management → [your Apple ID] → Trust**
6. Press **⌘R**

## 6. TestFlight build (for sharing with testers)

Requires a **paid Apple Developer Program** membership ($99/yr).

```bash
# Install EAS CLI (Expo's cloud build service)
npm install -g eas-cli
eas login

# First-time setup (creates eas.json)
eas build:configure

# Build for iOS (runs on Expo's Mac cloud — no local Xcode build needed)
eas build --platform ios --profile production
```

When the cloud build finishes, download the `.ipa` and upload it to
App Store Connect:

```bash
xcrun altool --upload-app -f vault-0.1.0.ipa -t ios \
  -u "your-apple-id@example.com" -p "app-specific-password"
```

(Generate the app-specific password at https://appleid.apple.com → Security.)

Then in **App Store Connect → TestFlight**: the build appears after
processing (~10–30 min) → add testers → they install via the TestFlight app.

## 7. Notes / gotchas

- **llama.rn** (on-device LLM): builds from C++ source on first iOS build —
  expect the first build to take 5–15 minutes. This is normal.
- The app is **portrait-only, iPhone-only** (`supportsTablet: false`,
  `orientation: portrait`) per `app.json`.
- Voice features need the microphone permission strings already declared in
  `app.json` (`NSMicrophoneUsageDescription`, etc.).
- If `npx expo run:ios` fails on CocoaPods, run `cd ios && pod install --repo-update`
  and retry.
- Never commit the generated `ios/` or `android/` folders — they're
  gitignored and regenerated by `expo prebuild`.

## 8. Useful commands

| Command | What it does |
|---|---|
| `npx expo start` | Start the dev server (use with Expo Go for quick JS-only preview) |
| `npx expo run:ios` | Prebuild + native build + run on Simulator |
| `npx expo prebuild --clean` | Regenerate `ios/` from scratch |
| `npx tsc --noEmit` | TypeScript check (should be zero errors) |
| `npx jest` | Run the test suite (73 tests) |
