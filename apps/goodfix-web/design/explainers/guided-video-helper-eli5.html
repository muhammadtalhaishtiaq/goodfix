Screen 4 · follow one step at a time

Use their video as the picture

Start with three short step cards. Each card uses a frame from the person’s own video, with a circle or arrow and a plain sentence.

That is safer and clearer than making a brand-new AI picture of a repair. A generated picture might show a part that is not really there.

How many pictures? Three still frames—one for each step. No need to generate three new images. A “next step” button keeps the page calm.

Screen 5 · ask, talk, or show again

Keep follow-up in the same session

The user does not need a separate “chat app.” Put the question box below the current step:

  • Type: “It still wiggles.”
  • Tap the mic and say it
  • Tap “Show what happened” to add one new photo or short clip

Then the assistant responds in the same thread and updates the next step. Every new upload gets its own clear send approval.

Three tiny user stories

What happens when…

“I can see the screw.”

The page points to the screw, shows step 1, reads it aloud if asked, then waits for “I did that.”

“I’m not sure.”

It offers a clearer picture or asks for one close-up. It does not pretend it knows.

“It got worse.”

Stop. The helper says not to continue, asks the user to keep clear if needed, and suggests a qualified person.

“Can I show you again?”

Yes. Add one follow-up picture or short clip in the same session, approve sending it, and get the next response there.

Try to break the idea

Safety and demo checks

Dangerous problem: If it sees exposed wires, gas, fire, major leaks, or structural damage, stop repair steps and advise getting qualified help.
Wrong or blurry video: Say “I can’t tell.” Ask for a clearer view or end the flow. Never invent a part.
Private faces or papers: Preview the clip before upload and let the person cancel or choose another clip.
Model/network fails: Say it could not check the clip. Keep the original video available for retry; do not show made-up steps.

Red-team result: “Repair anything” is too broad and risks unsafe advice. One supported, low-risk task and a visible stop path make a more believable demo. The exact repair category still needs testing against real clips.

Smallest convincing first version

Keep these four things

  1. One no-login webpage and one supported problem type.
  2. A short video, one plain-language send approval, and one clarifying question.
  3. Three step cards grounded in the user’s own video frames, with arrows and readable text.
  4. Text follow-up plus one optional re-upload. Add read-aloud; add voice input only if the main flow is already reliable.

Cut for the first demo: AI-generated repair pictures, unlimited uploads, every kind of home repair, accounts, and a separate chat area. The “smart” part is noticing, asking, guiding, and checking—not making lots of pictures.

This is a concept sketch, not a decision to replace Vault’s existing product plan. A public Meta-backed webpage also needs a safe, authorized way to call the model; never put a shared secret in the page.
