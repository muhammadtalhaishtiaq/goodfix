# 2026-08-01 — Engine decided, Phase 0 scaffolded, full wireframe set generated

Big session. Took Vault from "docs + a few screens" to a decided engine, a runnable Phase 0 de-risk scaffold, and the **complete** wireframe set.

## Decisions locked (see DECISIONS.md)
- **Hermes is Python → we BORROW, not fork.** Hermes-agent is Python; it can't run inside a React Native app. So we re-implement its agent/tool-calling *patterns* in our own TypeScript, on-device. Hermes = reference blueprint, not a dependency. Confirms Option C (our own bounded TS agent loop on `llama.rn` + RN on-device libs).
- **Hermes is MIT → legally cleared.** Confirmed the license (user pasted it). MIT lets us use/modify/ship/keep-closed; only obligation is an in-app "Open source licenses" screen (wireframed as screen 51).
- **Name: working = "Vault", clear the final before public beta.** Vetted 17 candidate names — all taken, several by direct competitors (Cove = "private AI apps, all on your phone, no cloud ever"; Numen; Mnema; Zeva; etc.). Conclusion: single dictionary/short words in AI are saturated; real clearance is a TM attorney's job, done once before launch. Build under "Vault" now (bundle id `app.vault.dev`); name swap pre-launch is a find-replace.
- **Accent color: deep teal `#0F766E`** (calm/trust/private), locked over amber/indigo/slate.
